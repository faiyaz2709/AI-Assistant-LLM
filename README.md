# AI Role-Based LLM Assistant

A Python-based AI chatbot built using the Groq API.

## Features

- Normal Chat Mode
- Role-Based Chat Mode
- Secure API key using .env
- Modular project structure
- Easy to extend with new roles

## Tech Stack

- Python
- Groq API
- python-dotenv

## Project Structure

- app.py
- llm.py
- prompts.py
- README.md
- requirements.txt

## Run

python app.py
